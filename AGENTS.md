# Repository Guidelines

## Project Overview

This is the Python 3 edition of Mika Lending Bot, an automated lending bot for
Poloniex and Bitfinex. The backend is a Python package under `src/lendingbot`.
Runtime configuration is TOML-based and validated with Pydantic models in
`src/lendingbot/modules/Configuration.py`.

The web dashboard is a React/TypeScript application under `frontend/`. It is
built with Vite, Ant Design, and ECharts. The bot serves generated production
assets from `www/` through the FastAPI web server in
`src/lendingbot/modules/WebServer.py`.

## Common Commands

Python setup and runtime:

```bash
uv sync
uv run lendingbot
uv run lendingbot --help
```

Python tests and checks:

```bash
uv run pytest -q
uv run poe check-full
uv run ruff check src/ tests/
uv run ruff format src/ tests/
uv run mypy src/
```

Frontend tests and build:

```bash
npm test
npm run typecheck
npm run build
```

Documentation:

```bash
uv run --group docs poe docs-html
```

Use `uv run --group docs` when Sphinx is not installed in the default
environment.

## Web Dashboard Notes

- Edit source files in `frontend/`.
- Run `npm run build` after frontend changes so the runtime assets in `www/`
  are updated.
- Commit both the relevant `frontend/` source changes and generated `www/`
  assets for frontend changes.
- Backend API route changes require restarting `uv run lendingbot`.
- The dashboard uses `/api/dashboard/state` for initial state and
  `/api/dashboard/state?include_logs=false` for lightweight polling.
- New log lines are streamed through `/stream-logs` using Server-Sent Events.
- Chart data is served through `/api/charts/history` from `www/history.json`.

## Important Paths

- `src/lendingbot/modules/Orchestrator.py`: main bot lifecycle and loop.
- `src/lendingbot/modules/Lending.py`: lending engine.
- `src/lendingbot/modules/WebServer.py`: FastAPI web server and dashboard API.
- `src/lendingbot/plugins/AccountStats.py`: lending-history database and
  earnings stats.
- `src/lendingbot/plugins/Charts.py`: chart history export.
- `frontend/src/`: React dashboard source.
- `www/`: generated dashboard runtime assets served by the bot.
- `docs/web_dashboard.rst`: web architecture documentation.

## Testing Guidance

For backend web changes, prefer focused checks first:

```bash
uv run pytest tests/test_WebServer.py tests/test_DashboardStatic.py -q
uv run mypy src/lendingbot/modules/WebServer.py
```

For AccountStats or Charts changes:

```bash
uv run pytest tests/test_AccountStats.py tests/test_Charts.py -q
```

For frontend dashboard changes:

```bash
npm test
npm run typecheck
npm run build
```

## Working Tree Rules

- Do not revert user changes unless explicitly asked.
- Generated dashboard assets in `www/` are intentional when frontend source
  changes are made.
- Avoid editing files under `docs/_build/`; they are generated by Sphinx.
- Keep commits scoped. Recent workflow has used separate commits for backend,
  frontend, and documentation changes.
